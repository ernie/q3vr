# Third-Party Software

Quake 3 VR includes the following third-party software:

## OpenAL Soft 1.25.1

- **License:** GNU Library General Public License, version 2 (LGPL v2)
- **License file:** `code/thirdparty/openal-soft-1.25.1/COPYING`
- **Source code:** https://github.com/kcat/openal-soft/releases/tag/1.25.1
- **Description:** Software implementation of the OpenAL 3D audio API.

OpenAL Soft is dynamically linked. You may substitute your own build of
OpenAL Soft (or any compatible OpenAL implementation) by setting the
`s_alDriver` console variable to the path of your preferred library.
